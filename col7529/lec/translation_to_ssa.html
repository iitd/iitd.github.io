Translation to Static Single Assignment (SSA) Form

Dominance Frontiers

The first step of the SSA translation algorithm is to identify the minimal set of convergence points at which trivial phi nodes need to be placed. This is done by computing the dominance frontiers of the nodes in the CFG.

Strict dominance: X strictly dominates Y (written X sdom Y) if X dominates Y and X ≠ Y.

  • Recall that the dominator relation is reflexive (every node dominates itself), but the strict dominance relation is not reflexive.
  • We write X !sdom Y to say that X does not strictly dominate Y; this relation is the complement of sdom. For example, B !sdom B always holds; and if B does not dominate C, then B !sdom C.

Dominance Frontier: The dominance frontier of a node X, written DomF(X), is the set of all nodes Y such that:

  • X does not strictly dominate Y (X !sdom Y), but
  • X dominates some predecessor P of Y.
DomF(X) = { Y | X !sdom Y  and  X dom P for some P in pred(Y) }

Intuition: if X dominates P and P-->Y is an edge, then there exists a path X-->...-->P-->Y where all the nodes from X to P are dominated by X (because every path from entry to P must go through X, and this includes the paths that go through the intermediate nodes). Y is the first node on this path that is not strictly dominated by X. In other words, look at all outgoing paths from X; on each path, the first node that X does not strictly dominate belongs to the dominance frontier of X. This is why the word frontier is used: it is the boundary at which X's (strict) dominance ends.

  • A node Z further down the path that is also not strictly dominated by X is not in DomF(X) if none of Z's predecessors are dominated by X.
  • Y may be dominated by X and yet be in DomF(X), if Y = X. e.g., if X is a loop header, then X may be in its own dominance frontier.

Example

Consider the following CFG (with edges entry-->A): 
A --> B, C
B --> D
C --> E
D --> B, F, G
E --> E, G
G --> F
Here, A dominates all nodes; B strictly dominates D; and C strictly dominates E. No other strict dominance relationships exist; e.g., F is not dominated by B because of the path A-->C-->E-->G-->F.
  • DomF(A) = {}: The only node not strictly dominated by A is A itself, but A's only predecessor is entry, which A does not dominate.
  • DomF(B) = {B, F, G}:
    • D is strictly dominated by B, so D is not in DomF(B).
    • F is not strictly dominated by B (path A-->C-->E-->G-->F), but F's predecessor D is dominated by B. Similarly for G.
    • B does not strictly dominate itself, but B dominates D, which is a predecessor of B (through the back edge D-->B). So B is in its own dominance frontier.
  • DomF(C) = {G}: C strictly dominates E, so E is not in the frontier. C does not strictly dominate G, but C dominates E, which is a predecessor of G.
  • DomF(D) = {B, F, G}: D does not strictly dominate any of its successors B, F, G; and D (which dominates itself) is a predecessor of each of them.
  • DomF(E) = {E, G}: G is not strictly dominated by E, but its predecessor E is dominated by E. Also, E is not strictly dominated by E, but its predecessor E (through the self-loop E-->E) is dominated by E. Here, X, Y, and P (in the definition) are all the same node E.
